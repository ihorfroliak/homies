## Why it matters

IBB-001 is the first single accepted Homies backend baseline. Before it, the
PRODUCT line (Phase-1A marketplace features) and the INFRA line (runtime, CI,
readiness) were two parallel histories from the same accepted ancestor. Each
was:

1. developed independently;
2. independently audited;
3. repaired where the audit required it;
4. independently accepted at an exact SHA;
5. converged by one real merge commit (CONV-001);
6. independently integration-audited (CONV-001A).

This ends the split product/infra topology. All subsequent backend work
descends from IBB-001 or a documented successor baseline, unless an explicit
governance decision authorises another ancestry.
